# blocks-dynamic-linear-001

block-heavy drawing, 3 entities, DWG AC1032, from https://github.com/DomCR/ACadSharp/blob/d7dc111023477d8a9fffc2153139459c95b4f345/samples/dynamic-blocks/BLOCKLINEARPARAMETER.dwg under MIT. A dynamic block with a linear parameter, reached through nested INSERTs.

I keep it for regression and for spotting differences between providers. It has no authored mathematics, so it is never `KNOWN_TRUTH_EXACT`; the class is `REAL_WORLD_DIFFERENTIAL`. Provenance and the licence basis are in `corpus/provenance.json`.
